Vehículo
No hay un dato confirmado de fábrica para tu Isuzu TFS 1998 4x4 turbo. Ajustá la capacidad cuando la confirmes (sticker de la tapa de gasolina, manual, o la próxima vez que lo llenés viniendo de casi vacío). El "rendimiento conservador" es el que se usa para calcular reserva/vacío — si lo dejás vacío, la app usa automáticamente el peor tramo que hayas registrado, para no quedarte corto.
Aceite
Metelo tal cual te lo diga el mecánico o la calcomanía del aceite. La barra de progreso arranca desde el kilometraje que tengas registrado ahora mismo — si cambiás este número después de un cambio de aceite real, el progreso se reinicia solo.
Sincronización entre dispositivos
Usa un Gist privado de tu cuenta de GitHub como almacenamiento compartido. Configurá lo mismo (token + ID del Gist) en cada dispositivo para que todos vean el mismo historial.
Paso 1 — generá un token
Andá a github.com/settings/tokens/new con el permiso gist ya marcado, generalo, y copiá el token (empieza con ghp_). Tratalo como una contraseña — no lo compartas ni lo pegues en otro lado.
Todavía no sincronizado.
