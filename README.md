# Tracker de Gasolina

App web para anotar tanqueos (fecha, odómetro, galones, monto) y calcular:

- Rendimiento (km/galón)
- Cada cuánto tanqueás
- Autonomía restante, reserva y vacío estimados
- Recordatorio de cambio de aceite

Sin backend ni build step — HTML/CSS/JS puro. Los datos se guardan en el
`localStorage` del navegador (no salen de tu dispositivo).

## Uso

Abrí `index.html` en un navegador, o serví la carpeta con cualquier servidor
estático (ej. GitHub Pages).
